# 💻 Amazon Laptop Web Scraper

A Python automation script that scrapes laptop listings from Amazon, extracts key product details (Title, Price, Rating), and structures them into a CSV file.

## 📌 Features
- Scrapes product titles, pricing, and customer ratings.
- Cleans and structures raw HTML data using Python.
- Exports formatted data into a clean `laptops.csv` file.

## 🛠️ Tech Stack & Tools
- **Language:** Python 3
- **Libraries:** `requests`, `beautifulsoup4`, `pandas`
- **IDE:** VS Code

## 📁 Output Data
Data is automatically saved in `laptops.csv` with columns:
`Title | Price | Rating`
